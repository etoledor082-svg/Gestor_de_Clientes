# Gestor_de_Clientes

Proyecto para acreditar la materia de programación orientada a objetos. 

Este proyecto consiste en crear un programa que funcione como una base de datos para cualquier tipo de negocio.

Se implementaron los temas vistos durante el curso de Programación Orientada a Objetos, los cuales son:

  -> Clases
  -> Métodos y atributos estáticos
  -> Arreglos de objetos
  -> Punteros
  -> Visualización de datos en formato de tabla
  -> Herencia de clases
  -> Constructores
    -> Sobrecarga
    -> Herencia
  -> Funciones amigas
  -> Sobrecarga de operadores

  El objetivo de este proyecto es consolidar los aprendizajes adquiridos a lo largo del curso y ponerlos en práctica para
  desarrollar herramientas útiles.
